# Alarm sounds

Five original instrumental alarm sounds, generated with the Python standard library only (no numpy, no ffmpeg).

    python3 scripts/alarm-sounds/generate.py            # all five, about 75 s
    python3 scripts/alarm-sounds/generate.py --only sunrise

- `sunrise` (default): rising arpeggio over a warm pad, 20 s. `chimes` 18 s, `marimba` 20 s, `piano` 18 s, `guitar` 18 s (Karplus-Strong).
- Mono 16-bit. Masters 44.1 kHz in `out/` (gitignored). Android build 32 kHz in `out/android/alarm_<id>.wav`.
- Seamless loops by construction: notes are mixed with wrap-around indexing, so tails flow back into the start. No baked fade.
- All five are RMS-normalised to about -18.4 dBFS with a soft limiter (peak at most -1 dBFS). This approximates, but is not, LUFS.
- Ship copies live in `mobile_app/modules/mylife-alarms/assets/sounds/`:
  `android/alarm_<id>.wav` (copy of `out/android`) and `ios/<id>.caf`, converted with:

      afconvert -f caff -d ima4@44100 -c 1 out/<id>.wav <id>.caf

Re-run both steps after changing the generator.
